## Ejemplo de datos de la aplicación

El archivo 'ejemplo_entrada_datos.xlsx' contiene un ejemplo de entrada de datos para la aplicación. Este archivo puede introducirse en la app Streamlit para procesar.

El archivo 'ejemplo_salida_resultados.xlsx' contiene la salida de resultados correspondiente al ejemplo de aarchivo XLSX contenido en esta carpeta. Junto al archivo Zip, que sería el resultado de descargar todos los cálculos comprimidos en un archivo, se incluyen los arachivos tabla_1.txt, tabla_2.txt y tabla_4.txt que contiene el Zip y que corresponden a la optimización individual de cada tabla, para facilitar su visualización.

El archivo de entrada contiene 4 tablas para su optimización. El ejemplo de salida se ha creado utilizando una longitud de barras en bruto de 600 cm. La tabla 2 contiene longitudes mayores a esta longitud de barra, por lo que la app ignora esta tabla al contener medidas no asignables.
